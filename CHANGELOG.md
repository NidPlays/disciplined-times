# Changelog

All notable changes to Disciplined Times. The project uses [Semantic Versioning](https://semver.org); see `AGENTS.md` for when to bump which number.

## 0.2.0

- **Week:** swipe left or right on the weekly chart to go to the next or previous week.
- Added `AGENTS.md` with contributor and agent guidelines, including per-PR versioning, and this changelog.

## 0.1.0

- First release: goals planned per day, week or month; quick time logging; Week view; themes with light and dark modes; installable, offline-capable PWA.
