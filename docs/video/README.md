# Promo video

A 38-second promo for Disciplined Times, made with [HyperFrames](https://hyperframes.heygen.com), an open-source tool that renders HTML, CSS and GSAP animations to MP4.

- **`disciplined-times.mp4`**: the finished video (1920×1080, 30 fps, with sound).
- **`preview.webp`**: a silent, looping preview for the main README. GitHub can't play an MP4 stored in a repo inline, so the README shows this and links to the MP4.

## What's in the video

| Time | Scene |
| --- | --- |
| 0–4 s | Hook: "Every week gives you 168 hours. Where did yours go?" |
| 4–8 s | The logo draws itself, then the name and tagline appear |
| 8–13.5 s | **01 · Plan**: goals per day, week and month; a weekday schedule lights up |
| 13.5–20 s | **02 · Log**: three taps on **+30 MIN** fill the ring, then the goal is done (confetti) |
| 20–24.5 s | **03 · Review**: the week chart grows and the per-goal heat strips fill in |
| 24.5–28.5 s | **Themes**: a fan of all 7 themes flips from dark to light |
| 28.5–32.5 s | The real app (screenshots) on phone and desktop, plus offline, no account and install badges |
| 32.5–38 s | "Plan it. Tap it. Own your time." and the link |

## Files

```
index.html         the composition: every scene, plus one GSAP timeline that drives them
gen_audio.py       synthesises the soundtrack (120 BPM groove + effects timed to the scenes)
make_preview.sh    builds preview.webp from the MP4
assets/            app screenshots, logo, soundtrack.m4a
vendor/gsap.min.js GSAP 3.15.0, vendored so renders work offline
hyperframes.json   HyperFrames project config
meta.json          HyperFrames project metadata
```

The colours come from the app's Midnight theme and the goal colours in `src/lib/themes.ts`. The theme fan uses each theme's real dark and light palettes. All the music and sound effects are generated by code, so there's no third-party audio to license.

## Re-render

You need Node 22+, FFmpeg, Chrome/Chromium (HyperFrames finds it or downloads one) and Python 3 with numpy.

```sh
cd docs/video
bun run dev       # live preview studio in the browser
bun run check     # lint, layout, contrast and motion checks
bun run build     # regenerate the soundtrack, render the MP4, rebuild preview.webp
```

`bun run build` runs `audio`, `render` and `preview` in that order, and you can run each one on its own too. If you change scene timings in `index.html`, change the matching effect times in `gen_audio.py` as well. The two files use the same timestamps.

If you update the app's screenshots in `docs/`, copy them into `assets/` and re-render.
